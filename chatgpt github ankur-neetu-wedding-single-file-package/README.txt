ANKUR & NEETU — SINGLE-FILE WEDDING INVITATION

Files:
  index.html
  assets/music/README.txt

The entire website code (HTML, CSS, JavaScript) is inside index.html.
To enable Aaj Sajeya playback, obtain a properly licensed MP3 and add it as:
  assets/music/aaj-sajeya.mp3

The HTML already points to that relative path. The MP3 is not included.
After adding it, upload index.html and the assets folder to the root of your
GitHub repository, then enable GitHub Pages from Settings > Pages.

Before publishing:
- Check the names and family details in the page.
- Confirm the exact venue pin/address.
- In the WEDDING object near the bottom of index.html, optionally set
  whatsappNumber to the family WhatsApp number including country code.
- Test the RSVP WhatsApp flow and countdown on a phone.

The guestbook is browser-local only. RSVP opens WhatsApp; neither feature
claims to save data to a shared database.
